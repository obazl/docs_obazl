## ocaml_ns

`load("@rules_ocaml//build:rules.bzl", "ocaml_ns")`

[.prototype]
pass:[
ocaml_ns(*, <a href="#ocaml_ns-name">name</a>, <a href="#ocaml_ns-import_as">import_as</a>, <a href="#ocaml_ns-ns_import_as">ns_import_as</a>, <a href="#ocaml_ns-ns_merge">ns_merge</a>, <a href="#ocaml_ns-ns_name">ns_name</a>, <a href="#ocaml_ns-private">private</a>, <a href="#ocaml_ns-submodules">submodules</a>, <a href="#ocaml_ns-visibility">visibility</a>)

Macro. Expands to an link:ocaml_ns_config[ocaml_ns_config] and an
link:ocaml_module[ocaml_module] target that together define an OCaml pseudo-namespace.
